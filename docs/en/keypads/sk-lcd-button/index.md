# FLEXi / Keypad SK-LCD button – Brief User Guide

> [!NOTE]
> The keypad “SK-LCD button” for alarm system control displays the states of **64 zones and 8 partitions**. Also, the “SK-LCD button” keypad can be assigned to control one or more desired areas (control panel firmware version from FW: SP3_xxx4_0121). The keypad will display the statuses of the assigned area and area zones.



## Alarm system arming / disarming

### Alarm system ARM

1. Make sure all zones are not violated.

2. Press the <img src="./image2.webp" alt="Closed-padlock button for arming an area." style="width:0.3500in;" /> button.

3. Enter User code.

4. Select the button of area to be activated.

5. Press <img alt="Checkmark button for confirming a selection." src="./image3.webp" style="width:0.3500in;" /> button.

6. Exit the premises within time delayed.

When the system is armed, the <img alt="Partition 1 armed indicator: number 1 beside a closed padlock." src="./image4.webp" style="width:0.3500in;" /> icon will light up.

### Alarm system DISARM

1. Enter User code.

2. Press the button of particular area you wish to disarm.

3. Press <img alt="Checkmark button for confirming a selection." src="./image3.webp" style="width:0.3500in;" /> button.

When the alarm is disarmed the <img alt="Partition 4 disarmed indicator: number 4 beside an open padlock." src="./image7.webp" style="width:0.3500in;" /> icon must be illuminated.

### SLEEP mode activation

(Premises perimeter is secured. Movement inside is allowed. If you open the entrance door, the alarm will actuate immediately):

1. Press <img alt="SLEEP mode button." src="./image5.webp" style="width:0.3500in;" /> button.

2. Enter User code.

3. Press the button of area to be activated.

4. Press <img alt="Checkmark button for confirming a selection." src="./image3.webp" style="width:0.3500in;" /> button.

5. SLEEP mode will turn on immediately, without exit delay.

The <img alt="Partition 3 SLEEP mode indicator." src="./image6.webp" style="width:0.3500in;" /> icon will illuminate when SLEEP mode is on.

### STAY mode activation

(Premises perimeter is secured. Movement inside is allowed. Any opening of entrance door enables time delay during which you have to disarm the alarm):

1. Press <img alt="Curved left-arrow button." src="./image10.webp" style="width:0.3500in;" /> button.

2. Enter User code.

3. Press the button of area to be activated.

4. Press <img alt="Checkmark button for confirming a selection." src="./image3.webp" style="width:0.3500in;" /> button.

5. STAY mode will turn on immediately, without exit delay.

The <img alt="Partition 2 STAY mode indicator." src="./image9.webp" style="width:0.3500in;" /> icon will illuminate when STAY mode is on.

> [!NOTE]
> For area status changing into the opposite one it is sufficient to enter User code and select the preferred area. To delete symbols or command entered, press button <img src="./image10.webp" alt="Curved left-arrow button." style="width:0.3500in;" />.





## Emergency buttons

### To send emergency message to your security service

- **Police** – hold **1** button pressed for 3 sec.

- **Medical Aid** – hold **4** button pressed for 3 sec.

- **Fire Service** – hold **7** button pressed for 3 sec.

## Illumination brightness and indication sound adjustment

### Brightness of the keypad buttons

1. Press <img alt="MENU button." src="./image11.webp" style="width:0.3500in;" /> button, then **5** **3**.

2. Select the preferred brightness of the keypad button backlight using the **2** and **8** buttons.

3. Press <img alt="Checkmark button for confirming a selection." src="./image3.webp" style="width:0.3500in;" /> to save the new value.

### The brightness of the LCD display

4. Press <img alt="MENU button." src="./image11.webp" style="width:0.3500in;" /> button, then **5** **2**.

5. Select the preferred illumination brightness of zone indication using **2** and **8** buttons.

6. Press <img alt="Checkmark button for confirming a selection." src="./image3.webp" style="width:0.3500in;" /> to save the new value.

### Keypad keystroke volume

7. Press <img alt="MENU button." src="./image11.webp" style="width:0.3500in;" /> button, then **5** **1**.

8. Select the preferred sound indication level using **2** and **8** buttons.

9. Press <img alt="Checkmark button for confirming a selection." src="./image3.webp" style="width:0.3500in;" /> to save the new value.
> [!NOTE]
> Turn off keypad lighting in standby mode. Pressing <img alt="MENU button." src="./image11.webp" style="width:0.3500in;" /> and then press **5** **4**. Switch the keypad indicator backlight status in standby mode by pressing **1** (backlight on) or **2** (backlight off). Press <img alt="Checkmark button for confirming a selection." src="./image3.webp" style="width:0.3500in;" /> to save the new value.

## Entering or changing / User or Master codes

### To enter a new or change the existing User code

1. Press <img alt="MENU button." src="./image11.webp" style="width:0.3500in;" /> button, then **0**.

2. Enter **Master** code, default code – 1234.

3. Enter User's double-digit sequence number, e.g., **02**.
> [!NOTE]
> Sequence number of **Master** code - **01**.

4. Enter a new User code twice.

5. Press the sequence numbers of areas which should be controlled by User.

6. Press <img alt="Checkmark button for confirming a selection." src="./image3.webp" style="width:0.3500in;" /> button. Press the <img alt="Curved left-arrow button." src="./image10.webp" style="width:0.3500in;" /> button to exit.

## Fire (smoke) detector reset

### To reset fire (smoke) detectors

- Hold button <img alt="Curved left-arrow button." src="./image10.webp" style="width:0.3500in;" /> pressed for 3 seconds.
> [!NOTE]
> Fire (smoke) detectors do not reset automatically after fire emergency detection. They can be reset only manually.

## Temporary zone monitoring deactivation (BYPASS function)

### BYPASS function activation

1. Press <img alt="MENU button." src="./image11.webp" style="width:0.3500in;" /> button, then **6**.

2. Enter the alarm control code.

3. Enter a double-digit sequence number of a particular zone to disable its monitoring. To disable the monitoring of several zones, enter double-digit numbers of such several zones.

4. Press <img alt="Checkmark button for confirming a selection." src="./image3.webp" style="width:0.3500in;" /> button. The icon <img alt="BYPASS indicator on the LCD screen." src="./image12.webp" style="width:0.3500in;" /> will appear on the LCD screen.

### BYPASS function deactivation

Repeat the same actions as in deactivation of particular zone monitoring.

## Deleting User codes

### To delete User code

1. Press <img alt="MENU button." src="./image11.webp" style="width:0.3500in;" /> button, then **0**.

2. Enter **Master** code.

3. Enter User's double-digit sequence number, e.g., **02**.

4. Press <img alt="SLEEP mode button." src="./image5.webp" style="width:0.3500in;" /> keypad button. A sound signal will be heard.

5. Press <img alt="Checkmark button for confirming a selection." src="./image3.webp" style="width:0.3500in;" /> button to exit.
