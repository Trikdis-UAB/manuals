# Snabbinstallation av DSC NEO HS2016 med GT/GT+/GET

Korta anvisningar för inkoppling och programmering när larmsändaren GT/GT+/GET ansluts till centralapparaten DSC NEO HS2016 via TIP/RING-plintarna, följt av registrering av systemet i Protegus2. Använd anvisningen tillsammans med de fullständiga manualerna för alla övriga inställningar. (Plintarnas beteckningar skiljer sig något mellan GT, GT+ och GET, men anslutningarna är desamma.) 

!!! caution "Försiktighet"
    Installation och service får endast utföras av behörig personal. Koppla bort matningen innan du drar ledningarna. Obehöriga ändringar upphäver garantin.

## Förutsättningar

1. GT/GT+/GET med firmware 1.21, SIM-kort isatt, PIN-kodsbegäran avstängd och aktivt dataabonnemang.
1. Centralapparat DSC NEO HS2016 med tillgång till knappsatsen (installatörskoden finns tillgänglig).
1. Abonnentkod hos larmcentralen, om rapportering sker till larmcentral.
1. Protegus2-konto för larmbolag/installatör och larmsändarens IMEI.

## Inkoppling

Anslut larmsändaren till centralapparaten enligt kopplingsschemat nedan: 

| **Plint på GT/GT+/GET** | **DSC-centralapparat** | **Anmärkning**                       |
| ----------------------- | -------------------- | ------------------------------------ |
| +12V DC/-12V DC         | +AUX/-AUX            | Matar larmsändaren                   |
| TIP/RING                | TIP/RING             | För emulering av PSTN-linje (Contact ID) |
| 1 I/O                   | Z1                   |                                      |

## Programmera centralapparaten DSC NEO HS2016 från knappsatsen

Ange följande sekvenser på centralapparatens knappsats och ställ in dem enligt beskrivningen:

**Aktivera rapportering med Contact ID**

| **Knappsatsinmatning** | **Beskrivning**                                       |
| ---------------- | ----------------------------------------------------- |
| *85555           | Gå in i programmeringsläge                            |
| 001*             | Öppna ”Sektionstyp”                                   |
| 066##            | Välj sektionstypen ”Till-/Frånkoppling (puls)”        |
| 301*             | Öppna ”Telefonnummer”                                 |
| <1234##          | Ange telefonnummer (1234)                             |
| 310*             | Öppna ”Abonnentkoder”                                 |
| 1111             | Ange systemets abonnentkod (1111)                     |
| 001              |                                                       |
| 2222#            | Ange abonnentkod för område 1 (2222)                  |
| 311              | Öppna ”Område 1, samtalsriktning”                     |
| 003*##           | Aktivera ”Till-/frånkopplingar” (J)                   |
| 350*             | Öppna ”Larmformat”                                    |
| 03#              | 03 – Contact ID-format.                               |
| ##               | Lämna programmeringsläget.                            |

!!! tip "Tips"
    Utför en systemkontroll när inställningarna och installationen är klara:

    1. Skapa en händelse:

       - genom att tillkoppla/frånkoppla systemet med centralapparatens knappsats.
       - genom att utlösa ett sektionslarm medan systemet är tillkopplat.

    2. Kontrollera att händelsen når larmcentralen (CMS) och Protegus2-appen.
